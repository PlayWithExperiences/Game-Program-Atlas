公开内容

页面公开展示根机构、学位项目、机构关联的教师姓名 / 公开职称，以及可访问的来源链接。当前数据是有公开来源约束的公开子集，不是全球完备普查。

用于核对公开事实的来源

学校官方项目页面

学位项目优先以学校官方项目详情页、研究生院 / 招生目录或官方招生页核对；项目名称需要能在来源页面中定位。未能核对的项目不会标记为已核。

机构与教师官方页面

机构地点、院系关系、教师名册和公开职称优先使用学校官方机构页、院系页、教师名册或个人官方页。页面没有说明的内容不会由名称或职称推断。

用于发现线索与补充背景的公开来源

论文与学术会议名单

公开论文作者 / affiliation、学术会议与会者或演讲者名单，可用于发现机构或人员线索，并补充研究方向背景。它们不能单独证明学位项目存在、当前任职或招生状态。

GDC 与 KMJN

GDC 官方 speaker / session / program 页面用于发现公开的行业与研究参与线索；KMJN affiliation index用于发现技术游戏研究侧的机构与人员线索。通过这些来源发现的内容，仍需回到学校官方页面核对后才能作为对应公开事实。

状态含义

“已核”表示对应官方页面提供了支持；“未核”表示尚未完成对应核对；“页面未说明”表示页面已访问但没有提到该事实；“读取失败”表示来源页面没有成功读取。不同状态不会合并成“没有”。
