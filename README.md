# Game Program Atlas · 全球游戏相关学位项目地图

**在线访问：https://playwithexperiences.github.io/Game-Program-Atlas/**

一份公开可查的世界游戏相关硕博项目地图。项目与机构事实以各校官方页面为最终证据，公开来源和统计口径另行标注；本项目只做整合，不做评价、不做排名、不做推荐。

## 数据从哪来，可信到什么程度

每条**已核**的公开项目记录都指向它的官方来源页，项目名必须能在该页正文中**逐字定位**才会收录。这条规则不是装饰——它挡掉了不少「听起来像游戏项目、官方页却从没这么写」的条目；未核项目不会被写成已核。页面内的「数据导览台」会把最终事实来源、发现 / 背景来源和公开下载内容分开说明。

导览台中的环图只统计根机构数量，条形图只统计项目记录数量；图形用于快速阅读，不代表项目质量、机构影响力或排名。国家明细表保留全部国家 / 地区和「未标注」行，是图表的精确核对入口；多校区、联合项目和线上项目会标注范围，但不强行映射到一个城市。

地点归属区分三种状态，任何时候都不合并：

- **已核实** — 官方页面直接明确了国家 / 地区。
- **已归属·推断** — 官方页面明确了机构身份和城市 / 区域，国家 / 地区由地理归属可靠推导；这不是官方页面直接表述。
- **未标注** — 目前还没有足够证据，不把空白伪装成结论。

项目页面另有自己的“已核 / 未核”状态；“页面未说明”和“读取失败”仍分别保留在相应证据账本中，不等同于地点未标注。

**抓取失败永远不记作「页面未说明」。** 读不到一个页面，和读了之后发现页面没写，是两件不同的事，混为一谈会把「我们不知道」伪装成「事实如此」。

同样地，公开教师信息只按公开页面列出的姓名、职称和机构关联整理，不从职称推断页面没有说明的事实。项目名能确认多个授予 / 交付机构时，会显示“联合 / 混合项目”；官方证据明确线上交付时，会显示“线上 / 远程”。

KMJN affiliation index（用户所称 KMGN 的对应规范名）是技术游戏研究侧的公开发现来源。部分线索也来自公开论文作者 / affiliation、学术会议与会者或演讲者名单，以及 GDC 官方 speaker / session / program 页面。它们用于发现可继续核对的机构或人员、补充研究 / 行业背景，不直接证明博士项目存在、当前任职或招生状态；通过这些来源发现的项目，仍须回到学校官方项目页、研究生院 / 招生目录或官方招生页核实。

### GPA 如何发布项目数据

GPA 自己负责项目身份、语义去重、证据合并和公开发布。外部或历史快照只是输入，
不会替 GPA 决定两个名称是不是同一个项目；这些决定记录在
`data/gpa-program-curation.json`，由 `tools/publish_gpa.py` 同时生成
`public-dataset.json`、`atlas-site-data.json` 和供第三方（包括 Radar）只读使用的
`gpa-catalog.json`。Radar 只读取 catalog 并返回 correction / evidence feedback，
反馈经 GPA 复核后才会进入下一次发布。

### 已知的不完整之处

这份数据不完整，而且我们更愿意把缺口说清楚，而不是让它看起来像已经查完了：

- 下面两条按机构记录节点统计，并与页面一样按当前具名关联计数：192 所有学位项目的机构里，**16 所还没有任何教师记录**，另有 36 所只有 1–2 位。归并到页面根机构后，仅 3 个有学位项目的根机构暂无具名记录。空记录不代表该机构没有教师。
- 当前公开图共有 235 所机构记录（含项目院系、研究组及公开教学 / 研究关联），235 所中 17 所无教师记录；它们归并为 194 个根机构。名册范围以相应院系、项目或研究组为界，不把相关院系所有人都称作游戏研究专家。
- 五轮调查原先空白的 110 个机构；第五轮重新检查39份部分名单、UTEG与UTEL，以及UNSW的两个未解缩写，新增10位公开成员。完整/部分状态以逐校官方边界为准；本轮已查渠道、实际访问失败和仍缺的名单材料见 docs/coverage-fifth-pass-20261013/completion-audit.json。UNSW CB Gagliano、BY Lin仍缺可靠身份桥，未猜测展开；校内登录大纲未越权访问。此前核实的4个姓名仍以本人职业主页作身份桥，任课关系由官方课程证实。
- ESDIE 的 Master en Videojuegos 被当前官网归为继续教育，现有证据不足以确认学术硕士学位，暂不列入已核学位目录；保留机构与具名成员。华东师大原“游戏与数字文创”方向按官方更名为“智能游戏交互”，保留原项目身份。
- 原先 24 个缺城市的目标已逐一核对：22 个补入城市点；NOVA 与 UNIAT 确为多城市记录。根机构中剩余 15 个多地点、4 个线上、1 个联合记录未设单一地图点；城市点不代表校区精确坐标。

## 页面怎么用

- 左侧搜索框可按机构、城市或教师名搜索。
- 「学位层级」「国家 / 地区」可多选叠加。
- 右上角「地图 / 表格」切换视图；表格视图的表头可直接筛选与排序。
- 「导出」把当前筛选结果存成 CSV。
- 页头「数据导览台」进入统计与来源导览；「返回地图」或按 Escape 返回主视图。
- 右上角可切换深色 / 浅色主题。

## 隐私

本仓库只包含公开可查询的信息：机构名、学位项目名、官方页 URL、以及各校官方页面上公开列出的教师姓名。

仓库只发布机构、项目、公开成员和来源字段，不维护个人联系方式字段或私人评估；校方原文摘录可能包含公开工作联系方式。公开字段与输出文件均经过白名单校验。

如果你是本数据中被列出的教师，希望移除自己的条目，请开一个 issue 说明，我们会移除。

## 数据文件

`public-dataset.json` 是完整数据集，可直接下载使用：

```bash
curl -O https://playwithexperiences.github.io/Game-Program-Atlas/public-dataset.json
```

`gpa-catalog.json` 是 GPA 面向第三方公开消费者的最小机构/项目目录：

```bash
curl -O https://playwithexperiences.github.io/Game-Program-Atlas/gpa-catalog.json
```

它只包含公开项目事实、机构归一化信息和官方证据状态，不是排名。

页面实际读取精简的 `atlas-site-data.json`，教师公开来源在打开抽屉时按需读取 `atlas-person-evidence.json`；完整数据集仍保留供下载。这样首屏不必为未打开的数千条教师来源等待下载，也不改变公开数据的完整下载内容。

结构：`programs` / `organizations` / `people` / `routes` / `cities`。机构地点字段包含 `location_state` 与 `location_scope`；页面展示的是公开字段，未标注、已归属·推断、未核和读取失败等状态按各自含义保留。

### 研究中心与研究生态

2026-10-14 统一核实口径后，公共目录收录 **239条研究组织记录、53个国家/地区，其中美国49条**；231条身份与游戏相关方向已核、6条历史、2条筹建。身份核实与活动时效分开：3条明确标为现行活动未确认，2条提供具年份的活动材料，其余234条活动时效未单独核对，绝不默认当前活跃。ISTaR按游戏相关交叉研究收录，不称专门游戏研究中心。[公共条目、官方来源与核查状态](research-ecosystem.json)。

[GPA 研究组织目录](ecosystem.html) 原生展示研究中心、机构和学位项目；[Learn About Games](https://playwithexperiences.github.io/Learn-About-Games/) 专注游戏变迁、设计知识与学习资源，两站通过链接互通；[统一公共数据](research-ecosystem.json) 由本项目同一发布流程生成。中心独立于学位项目，身份状态、官方来源与核查日期可追溯；中心登记不等于正在招生，也不代表全球覆盖完整。私人适配评分和申请判断不属于该公共目录。

研究生态也包含按方向明确标注的 HCI / 设计研究相邻实验室；收录不意味着专门从事游戏研究、开设游戏学位或正在招生。

## 公开申请日历

[申请日历](https://playwithexperiences.github.io/Game-Program-Atlas/calendar.html) 在月历上查看近期截止，在完整表格中搜索并按倒计时、日期、名称、地区或类型排序。范围含游戏及互动媒体／设计相邻方向的硕博、奖学金、教职与研究岗位；相邻方向明确标注，不改变学位目录收录标准。

公开数据为逐条审阅的有限清单，不是全球完整招生名录。每条保留官方来源、来源时区、核查日期和历史证据状态；年度惯例不自动变成当年日期，没有确定日期的机会只在表格显示。日期已过不推断岗位去向，日期未过也不保证仍有名额。官网延期与前置申请轮次以原公告为准。

维护：申请日历已接入机会雷达的共同刷新流程。Radar 先核对V2官方事实与公开发布审阅，未核实的新条目、变化的原文及冲突信息进入待核实清单；GPA 同步器生成公开文件，通过验证后仅提交两份日历数据并核对线上结果。私人适配评分、联系记录和申请计划不进入公共数据。`data/application-calendar-input.json` 是生成文件，不再手工维护第二份清单。

独立同步与发布：`python3 tools/sync_application_calendar.py --radar-root <Radar仓库> --publish`。省略 `--publish` 只更新本地；失败会保存错误状态，不能被当作“没有新机会”。网页每次加载重新核对公开数据缓存，各条核验日期保持真实，不因一次同步而重置。

日历下方的表格同时完整收录当前 GPA 目录的长期博士、硕士项目，不要求先有招生轮次或截止日期。长期项目与具体轮次／岗位分开筛选、分开计数；没有核实到日期就明确标注，年度月日参考不自动转成当年截止。GPA 项目目录更新和 Radar 机会同步都会重建这层完整覆盖。
