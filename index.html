      来源与方法

      最终事实来源：学校官方页面

      项目最终以学校官方项目详情页、研究生院 / 招生目录或官方招生页面核实；机构地点、教师名册和个人资料也优先使用学校官方页面。

      第三方聚合页、会议 affiliation、实验室名称不能单独替代项目级官方证据。

      发现与背景来源：论文、会议与 GDC

      部分机构或人员线索来自公开论文作者 / affiliation、学术会议与会者或演讲者名单，以及 GDC 官方 speaker / session / program 页面；KMJN affiliation index 也用于技术游戏研究侧的公开线索发现。它们用于发现可继续核对的机构或人员、补充研究 / 行业背景，不替代学校官方项目页、招生目录或官方教师页。

      来源标注：论文、会议与 GDC = 发现或背景来源；学校官方项目页、招生目录和教师名册 = 对应公开事实的主要核对来源。

      论文、会议和 GDC 页面不能单独证明学位项目存在、当前任职或招生状态；通过这些来源发现的线索仍需回到学校官方页面核对。
